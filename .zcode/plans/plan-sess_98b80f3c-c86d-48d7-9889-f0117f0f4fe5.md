# PWA 集成方案

## 概述

为 vant-starter-kit 项目添加 PWA（Progressive Web App）支持，采用 `vite-plugin-pwa` 作为 PWA 解决方案，并将集成方案文档化保存到 `docs/` 目录。

---

## 交付物

### 1. 新建文档：`docs/pwa-integration.md`

遵循现有文档风格（中文、日期块引用、编号章节、代码块、表格），内容包括：

- **一、背景与目标** — 什么是 PWA，为什么移动端项目需要 PWA
- **二、技术选型** — 对比 vite-plugin-pwa / Workbox / 其他方案，说明选择理由
- **三、安装与配置** — pnpm catalog 版本管理、依赖安装步骤
- **四、插件架构设计** — 遵循 build/plugins/ 工厂函数模式，插件组合方式
- **五、PWA 配置详解** — manifest 配置、Service Worker 策略（precache / runtimeCaching）、更新机制、图标配置
- **六、移动端专项优化** — iOS Safari 兼容处理、Vant UI 组件缓存策略、离线体验优化、App Shell 架构
- **七、开发调试** — 浏览器 DevTools 验证、Lighthouse 审计、Dev 模式启用 PWA
- **八、生产部署注意事项** — HTTPS 要求、scope 配置、更新提示 UI
- **九、相关文件** — 列出所有涉及的源文件及其作用

### 2. 代码变更（4 个文件）

| 文件                   | 变更内容                                                      |
| ---------------------- | ------------------------------------------------------------- |
| `pnpm-workspace.yaml`  | 在 `catalog:` 下新增 `'vite-plugin-pwa': '^1.0.0'`            |
| `package.json`         | 在 `devDependencies` 下新增 `"vite-plugin-pwa": "catalog:"`   |
| `build/plugins/pwa.ts` | **新建** — 导出 `createPwaPlugin()` 工厂函数，配置 `VitePWA`  |
| `build/index.ts`       | 导入并注册 `createPwaPlugin()`，仅生产构建启用（或 dev 可选） |

---

## 关键设计决策

1. **遵循现有插件模式** — 工厂函数命名 `createPwaPlugin()`，返回 `PluginOption`，与 `createTailwindcssPlugin`、`createNitroPlugin` 保持一致
2. **默认生产启用** — PWA 插件默认仅在 `isBuild` 时激活，dev 模式通过配置开关可选启用
3. **registerType: 'autoUpdate'** — 自动更新 SW，适合移动端场景，无需用户手动确认
4. **runtimeCaching 针对 Vant** — 为 Vant CSS/JS 资源添加 `CacheFirst` 策略，减少重复下载
5. **图标占位** — 文档中提供图标尺寸规格表，实际图标由开发者自行放置到 `public/` 目录
6. **版本写入 catalog** — 所有依赖版本统一在 `pnpm-workspace.yaml` 管理
